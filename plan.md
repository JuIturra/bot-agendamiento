# Idea
## Asistente WhatsApp + IA para negocios tradicionales
Nichos con dolor claro:

Talleres mecánicos / desabolladuras
Peluquerías y barberías
Veterinarias pequeñas
Estudios contables y de abogados chicos
Clínicas dentales y kinesiólogos (ya lo tienes)
Servicios técnicos (gasfitería, electricidad, aires acondicionados)

Qué resuelve:

Responder fuera de horario, agendar, dar precios básicos, filtrar clientes serios y avisar al dueño solo cuando hay algo concreto.
Modelo de cobro: 20-35 mil CLP mensuales + setup inicial bajo.

Es recurrente y relativamente fácil de vender de forma local.

Setup en railway hay un capa gratuita para empezar mostrando demos, con un primer cliente se puede tener la version basic e ir escalando segun la cantidad de clientes que ingresan, como su informacion es limitada no van a llenar tanto la base de datos con informacion propia, los datos de agendamientos quedan guardados en google calendar y postgres, pero se van borrando despues de algunos meses al no ser necesarios.

La idea es mostrar un demo que sea de alto impacto, que vean en accion como responde dudas del negocio y agenda de forma automatica.

Al principio para pruebas locales hacerlo con telegram para que sea mas barato, luego cuando se quiera mostrar un demo agregar la conexion a whatsapp
